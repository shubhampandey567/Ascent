# Changelog

All notable changes to Ascent are recorded here. Lesson-id changes are always listed, because they affect learners' progress data. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-09-24
### Added
- Curriculum: 10 phases over 72 plan-weeks (about 260 lessons, 10 projects, 10 exams) plus 4 consolidation weeks, with free resources verified in September 2026.
- The Mentor: `AGENTS.md` and 12 Agent Skills (`/start`, `/today`, `/quiz`, `/recall`, `/explain`, `/stuck`, `/submit`, `/weekly`, `/exam`, `/cards`, `/replan`, `/progress`) for Google Antigravity, Claude Code, GitHub Copilot, Cursor, Codex, OpenCode, Gemini CLI, Windsurf and other `AGENTS.md`-aware agents.
- `tools/tracker.py`: event log, pace against the plan, alerts, dashboard (`tracker/progress.md`), weak-spot tracking and weekly reports.
- `tools/srs.py`: spaced-repetition scheduler (modified SM-2). `tools/transcript.py`: YouTube transcripts for video-grounded quizzes.
- Guides: how to learn, why this path, free compute, rubrics, resource library. Docs: agent setup, guide for mentors and parents, architecture, research notes.
- Open-source setup: licenses, contributing guide, code of conduct, security policy, issue and PR templates, CI (tests, adapter sync, template hygiene) and a weekly link check.
