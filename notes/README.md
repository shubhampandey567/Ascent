# My Notes

Your notes, in your own words. The Mentor reads them to check your understanding but never writes them for you.

## The rule: write from memory first
1. Finish the video or reading. Close it.
2. Write the note **from memory** (this is retrieval practice, the single most effective study habit).
3. Only then reopen the source, fix mistakes, and mark each fix with `✱ fixed:` so you can see what you had wrong.
4. Keep it short. One page per lesson is plenty.

## File naming
`notes/P<phase>/<lesson-id>-<short-topic>.md`, for example `notes/P3/P3-W1-L2-matrix-multiplication.md`.

## Template (copy for each lesson)

```markdown
# <Topic> — <lesson id> — <date>

## In one sentence
<the core idea>

## Explain it to a friend (max 8 sentences, no jargon)
<as if to a smart friend who is not in tech>

## Example
<a worked example, a tiny code snippet, or a diagram in words>

## Connects to
<what you already knew that this builds on; what it will be used for later>

## Still fuzzy
<questions to ask the Mentor with /explain>

## Traps
<mistakes you or others commonly make here>
```
